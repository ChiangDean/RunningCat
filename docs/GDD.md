## 二、貓咪屬性

每隻貓咪擁有以下基礎數值：

| 屬性 | 說明 |
|------|------|
| MaxHP | 最大血量 |
| CurrentHP | 當前血量 |
| ATK | 攻擊力，決定對敵方造成的傷害 |
| DEF | 防禦力，採**遞減式減傷**（參考 LoL 公式），無限堆疊不會超過上限減傷率 |
| Speed | 左右橫移速度，影響移動及硬直時間 |
| Weight | 重量，決定撞擊後回彈距離 |
| 被動技能 | 全隊 buff、敵方 debuff，戰鬥開始即生效 |
| 主動技能 | 每隔 X 秒自動發動，玩家可設定**起始施放時間點** |

> ⚠️ 未來可能新增更多屬性（如：元素、穿甲...）

### DEF 減傷公式

```
減傷率 = DEF / (DEF + 100)
```

| DEF 值 | 減傷率 |
|--------|--------|
| 0 | 0% |
| 50 | 33.3% |
| 100 | 50% |
| 200 | 66.7% |
| 300 | 75% |
| 400 | 80% |
| 900 | 90% |

- 遞減設計讓堆疊防禦邊際效益下降，永遠不會達到 100% 減傷
- 未來可加入「無視防禦」效果，直接削弱對方 DEF 計算值

## 三、戰鬥系統

### 3-1 陣型配置

```
[ 我方隊伍 ]                    [ 敵方隊伍 ]
Cat5 Cat4 Cat3 Cat2 Cat1  →←  Cat1 Cat2 Cat3 Cat4 Cat5
                    碰撞區
```

- 我方：左側，面朝右；Cat1 在最右（前排），依序往左排
- 敵方：右側，面朝左；Cat1 在最左（前排），依序往右排
- 同隊不碰撞，對方互相碰撞
- **最大上場數：5 隻**（上限由關卡進度解鎖）
- 初始 1 隻，解鎖順序隨關卡推進增加

### 3-2 戰鬥流程

1. **倒數 60 秒**開始
2. 雙方所有存活貓咪**往中間移動**
3. 前排接觸 → **碰撞判定**
4. 計算傷害、回彈距離、硬直時間
5. 技能冷卻時間到 → **自動發動**（無距離限制）
6. 貓咪死亡 → **拋物線彈飛出畫面** → 從戰鬥列表移除
7. 下一隻貓前進 → 重複撞擊
8. 60 秒內消滅全部敵方 → **勝利**；否則 → **失敗**

### 3-3 碰撞計算

| 計算項目 | 說明 |
|---------|------|
| 傷害 | ATK 對方 DEF 減傷後扣血 |
| 回彈距離 | 由雙方 Weight 差決定；設有最短/最長回彈上限 |
| 硬直時間 | 碰撞後 **0.2 秒**無法攻擊；撞牆為 **0.3 秒** |
| 硬質期間被攻擊 | 不會反擊，等硬直結束後的下一次碰撞才算 |

### 3-4 牆壁反彈

- 每幀檢查角色是否超出螢幕邊界
- 若超出：判定撞牆 → 計算牆壁反彈 → 回彈回戰場
- 撞牆硬直時間 +0.1 秒（0.3 秒）

### 3-5 貓咪死亡

- 往反方向**拋物線彈飛**，不受牆壁限制
- 飛出畫面後從戰鬥列表移除（節省記憶體）

### 3-6 快速戰鬥系統

戰鬥開始時先在**邏輯層預先模擬**整場戰鬥：

| 模式 | 行為 |
|------|------|
| 正常模式 | 照事件序列播放完整動畫 |
| 加速模式 | 加快播放動畫 |
| 快速模式 | 直接顯示最終結果 |

三種模式使用**相同事件序列**，保證結果一致。

## 四、貓咪種類

### 角色列表（初版規劃）
牛奶貓、三花貓、忍者貓、賓士貓、大橘貓、黑貓
（未來：蝙蝠貓 等）

### 職業屬性類型

| 類型 | 特性 | 玩法 |
|------|------|------|
| 坦克貓 | 高 HP & 高 Weight | 卡位阻擋，撞牆硬直減少 |
| 刺客貓 | 高 ATK & 高 Speed | 瞬間衝刺、連續撞擊，先手打前排後撤退 |
| 防守貓 | 高 DEF & 中 Weight | 反彈傷害、硬直抗性，保護隊伍 |
| 飛行/跳躍貓 | 中 ATK & 高 Speed | 跳過敵前排，直接撞後排 |
| 元素貓 | 火/水/木屬性加成 | 撞擊附加元素效果，利用相剋 |
| 趣味萌寵貓 | 高 HP & 低 ATK | 趣味技能（如吐泡泡干擾），娛樂/收藏向 |
| 高速貓 | 高 Speed | 先手衝撞，短距離穿透 |
| 反彈貓 | 中高 Weight & 中 ATK | 利用牆壁/敵人排列造成連鎖傷害 |

## 五、強化系統

### 5-1 道具總覽

| 道具 | 用途 | 獲取方式 |
|------|------|---------|
| 普通乾糧（Cat Food） | 自動升級全屬性（HP / ATK / DEF） | 關卡掉落、任務、活動 |
| 特殊乾糧（Special Cat Food） | 自由分配點數給 HP / ATK / DEF 其中之一 | 關卡掉落、任務、活動 |
| 貓咪罐頭（Cat Can） | 提升 Weight（附加硬直抗性/撞擊威力）（未來實作） | 關卡中高稀有掉落、日常任務 |
| 貓咪鬍鬚（Cat Shard） | 技能升級 / 升星 / 品階（未來實作） | 關卡掉落、商店、活動 |
| 特殊技能書 | 解鎖/強化技能（MVP 後加入） | 高難度關卡、活動、商店 |
| 金幣 | 購買道具（未來實作） | 戰鬥獎勵、日常任務、活動 |
| 鑽石 | 重置強化時的費用（目前 0 鑽石） | 未來活動、課金 |

### 5-2 普通乾糧升級

- 每隻貓咪都有**普通乾糧等級**（Lv.1 起算，無上限，系統目前限制 **Lv.30**）
- 升一級**自動**依 Config 成長值提升 HP / ATK / DEF 三個屬性
- **升級費用公式：** `cost(lv) = (lv + 1)²`

| 目前等級 | 升一級花費 |
|--------|---------|
| Lv.1 → Lv.2 | 4 |
| Lv.2 → Lv.3 | 9 |
| Lv.3 → Lv.4 | 16 |
| Lv.N → Lv.N+1 | (N+1)² |

### 5-3 特殊乾糧分配

- 玩家可自由將點數分配給 HP / ATK / DEF 其中之一
- 每分配一點，**該屬性**依 Config 成長值提升（與普通乾糧成長值相同）
- 每分配一點的費用：設 n 為目前已分配的總點數（0-based），下一點花費 `n + 1`
- 累計消耗公式（用於重置退回計算）：`f(n) = 0+1+2+...+(n+1) = (n+1)(n+2)/2`

| 目前已分配（n） | 下一點費用 | 累計已消耗 f(n-1) |
|-------------|---------|--------------|
| 0 點 | 1 | 0 |
| 1 點 | 2 | 1 |
| 2 點 | 3 | 3 |
| 3 點 | 4 | 6 |
| 4 點 | 5 | 10 |
| n 點 | n+1 | n*(n+1)/2 |

### 5-4 屬性成長值（每點固定加成）

各貓咪在 Config（`enhancement_growth`）中設定，普通乾糧與特殊乾糧共用：

| 貓咪 | HP / 點 | ATK / 點 | DEF / 點 |
|-----|--------|---------|---------|
| 牛奶貓（坦克） | +2.0 | +0.5 | +1.5 |
| 其他貓咪（預設） | +1.5 | +1.0 | +0.5 |

> 未來新增貓咪時，在各自的 JSON Config 中設定 `enhancement_growth`，不需修改程式碼。

### 5-5 屬性顯示格式

強化畫面中的屬性顯示規則：
- 普通乾糧加成直接累加到基礎值顯示
- 特殊乾糧加成以 `+N` 形式附加在後方

```
HP:  1002 +4    ← 基礎1000 + 普通乾糧+2 + 特殊乾糧標示+4
ATK: 150        ← 無特殊乾糧加成時不顯示 +0
DEF: 53 +3
```

### 5-6 重置機制

- 按下「重置」後彈出確認視窗，顯示退回數量與鑽石費用
- 確認後**全部素材完整退回**（普通乾糧 + 特殊乾糧）
- 目前費用：**0 鑽石**（未來可接入鑽石消費邏輯）
- 退回計算公式：
  - 普通乾糧：`sum of (n+1)² for n in [1, cat_food_level-1]`
  - 特殊乾糧：設已分配總點數為 n，退回 = `n*(n+1)/2`（即 0+1+2+...+n 的加總）

### 5-7 UI 流程

```
強化主畫面
  └─ 選擇貓咪
      └─ 貓咪詳細面板
            ├─ 資源顯示（普通乾糧 / 特殊乾糧 / 金幣）
            ├─ 屬性顯示（基礎 + 普通加成，特殊加成附註）
            ├─ 普通乾糧升級
            │     ├─ [升級]（直接扣材料，無確認）
            │     └─ [一鍵升至 Lv.30]（彈出確認視窗）
            ├─ 特殊乾糧分配（HP / ATK / DEF 各 [+] 按鈕）
            │     └─ 每次點 + 直接扣材料，無確認
            └─ [重置（退回全部素材）]（彈出確認視窗）
```

## 六、關卡系統

### 關卡結構與通關規則

本遊戲採用三層關卡架構，由「遭遇戰」、「Boss 關」、「區域」與「領地」逐層組成，搭配線性進度解鎖機制。

#### 一、關卡組成

**遭遇戰（Encounter）**
最基本的遊玩單位，每一關提供短時間挑戰。

**Boss 關（Boss Stage）**
每個 Boss 關由以下內容組成：
- 4 個遭遇戰
- 1 個頭目戰（Boss）

關卡表示方式：`1-1、1-2、1-3、1-4、1-BOSS`

#### 二、區域（Zone）
- 每個區域由 **10 個 Boss 關** 組成
- 命名方式：新手 I、新手 II ...
- 玩家需依序完成區域內所有 Boss 關，才能解鎖下一個區域

#### 三、領地（Territory）
每個領地由 **5 個區域** 組成，範例：
- 新手 I → 新手 II → 新手 III → 新手 IV → 新手 V

#### 四、進度與解鎖規則
- 玩家需依序完成：遭遇戰 → Boss 關 → 區域 → 領地
- 完成某區域最終 Boss 關（第 10-BOSS）→ 解鎖下一個區域
- 完成某領地最終區域（第 V 區域）→ 進入下一領地的第 I 區域第 1-1

#### 五、進度記錄方式
玩家進度以**單一整數（`current_global_stage`）**記錄，從數字即可還原所有層級資訊：

```
全局編號 1 = 1-1（Boss 關第 1 關、遭遇戰第 1 關）
全局編號 4 = 1-4
全局編號 5 = 1-BOSS
全局編號 6 = 2-1
全局編號 50 = 10-BOSS（區域 I 最終 Boss）
全局編號 51 = 1-1（區域 II 第一關）
```

計算公式（每個 Boss 關 = 5 格）：
```
Boss 關序號 = ceil(global / 5)
遭遇戰索引 = ((global - 1) % 5) + 1   # 1~4=普通, 5=Boss
```

#### 六、通關規則
- 遭遇戰 1~4：**自動推進**，勝利後立即進入下一關
- Boss 戰：需玩家手動按下「挑戰 Boss」按鈕才開始
- Boss 失敗：退回該 Boss 關的第 4 遭遇戰，「挑戰 Boss」按鈕保持顯示
- Boss 挑戰**無次數限制**
- **自動推關模式**：連續自動打遭遇戰 1~4 → Boss → 重複；任何關卡失敗即停在該關

### 關卡難度自動計算

敵方數值由程式依 `current_global_stage` 自動計算，無需手動設定。
Stage 與 Boss 採**分開軌道**複利成長：

| 類型 | 成長係數 | 說明 |
|------|---------|------|
| 普通遭遇戰（Stage） | ×1.003 / 關 | 每進一遭遇戰累積 +0.3%，跨 Boss 關連續計算 |
| Boss 關 | ×1.02 / Boss 關 | 依全局 Boss 關序號累積 +2%，獨立於普通關軌道 |

**倍率範例（敵方數值相對 1-1 的比例）**

| 關卡 | 全局編號 | 倍率 |
|------|---------|------|
| 1-1 | 1 | ×1.000 |
| 1-4 | 4 | ×1.009 |
| 1-BOSS | 5 | ×1.020 |
| 2-4 | 9 | ×1.027 |
| 2-BOSS | 10 | ×1.040 |
| 10-4 | 49 | ×1.159 |
| 10-BOSS | 50 | ×1.219 |
| 50-BOSS | 250 | ×2.692 |

> 設計理念：普通關讓玩家輕鬆推關、獲得成就感；Boss 才是真正的強度門檻。

### 放置/離線獎勵
- 每**分鐘**計算一次獎勵（在線 & 離線皆算）
- 每小時固定 60 個貓咪乾糧 + 隨機道具
- 獎勵量與**當前關卡進度**成正比
- 推進越深，放置收益越高

## 八、競技場（PvP）

- **異步模式**：打對方的防守隊伍紀錄
- 使用與一般戰鬥相同的模擬系統
- 勝利加分、失敗扣分

### 牌位系統

| 牌位 | 階級 | 晉升條件 |
|------|------|---------|
| 銅牌 | III → II → I | 積分累積 |
| 銀牌 | III → II → I | 積分累積 |
| 金牌 | III → II → I | 積分累積 |
| 白金 | III → II → I | 積分累積 |
| 鑽石 | III → II → I | 積分累積 |
| 大師 | III → II → I | 依全服百分比（PR）計算 |
| 菁英 | — | 全服前 100 名 |

> 例：銅牌 III → 銅牌 II → 銅牌 I → 銀牌 III → ...→ 鑽石 I → 大師

### 大師牌位（PR 計算）

| 牌位 | 條件 |
|------|------|
| 大師 III | PR 0 ～ 50（後 50%） |
| 大師 II | PR 10 ～ 49 |
| 大師 I | PR 1 ～ 9（前 10%） |
| 菁英 | 全服前 100 名 |

## 九、技能系統

### 被動技能
- 戰鬥開始即生效
- 效果：全隊 buff（如冷卻 -10%）或敵方 debuff

### 主動技能
- 每隔 X 秒**自動發動**（玩家無法手動觸發）
- **起始施放時間**在配置畫面設定，流程如下：
  1. 玩家將貓咪拖曳至出戰位置
  2. 貓咪圖示下方顯示技能圖示及**秒數格子**（預設為 0）
  3. 點擊秒數格子 → 彈出 0～9 的數字按鈕
  4. 點選數字即設定首次發動時間（僅支援個位數 0～9 秒）
- 無距離限制
- 硬直期間冷卻繼續計算，但需硬直結束後才能發動
