## 二、貓咪屬性

每隻貓咪擁有以下基礎數值：

| 屬性 | 說明 |
|------|------|
| MaxHP | 最大血量 |
| CurrentHP | 當前血量 |
| ATK | 攻擊力，決定對敵方造成的傷害 |
| DEF | 防禦力，採**遞減式減傷**（參考 LoL 公式），無限堆疊不會超過上限減傷率 |
| Speed | 左右橫移速度，影響移動及硬直時間 |
| Weight | 重量，決定撞擊後回彈距離 |
| 被動技能 | 全隊 buff、敵方 debuff，戰鬥開始即生效 |
| 主動技能 | 每隔 X 秒自動發動，玩家可設定**起始施放時間點** |

> ⚠️ 未來可能新增更多屬性（如：元素、穿甲...）

### DEF 減傷公式

```
減傷率 = DEF / (DEF + 100)
```

| DEF 值 | 減傷率 |
|--------|--------|
| 0 | 0% |
| 50 | 33.3% |
| 100 | 50% |
| 200 | 66.7% |
| 300 | 75% |
| 400 | 80% |
| 900 | 90% |

- 遞減設計讓堆疊防禦邊際效益下降，永遠不會達到 100% 減傷
- 未來可加入「無視防禦」效果，直接削弱對方 DEF 計算值

## 三、戰鬥系統

### 3-1 陣型配置

```
[ 我方隊伍 ]                    [ 敵方隊伍 ]
Cat5 Cat4 Cat3 Cat2 Cat1  →←  Cat1 Cat2 Cat3 Cat4 Cat5
                    碰撞區
```

- 我方：左側，面朝右；Cat1 在最右（前排），依序往左排
- 敵方：右側，面朝左；Cat1 在最左（前排），依序往右排
- 同隊不碰撞，對方互相碰撞
- **最大上場數：5 隻**（上限由關卡進度解鎖）
- 初始 1 隻，解鎖順序隨關卡推進增加

### 3-2 戰鬥流程

1. **倒數 60 秒**開始
2. 雙方所有存活貓咪**往中間移動**
3. 前排接觸 → **碰撞判定**
4. 計算傷害、回彈距離、硬直時間
5. 技能冷卻時間到 → **自動發動**（無距離限制）
6. 貓咪死亡 → **拋物線彈飛出畫面** → 從戰鬥列表移除
7. 下一隻貓前進 → 重複撞擊
8. 60 秒內消滅全部敵方 → **勝利**；否則 → **失敗**

### 3-3 碰撞計算

| 計算項目 | 說明 |
|---------|------|
| 傷害 | ATK 對方 DEF 減傷後扣血 |
| 回彈距離 | 由雙方 Weight 差決定；設有最短/最長回彈上限 |
| 硬直時間 | 碰撞後 **0.2 秒**無法攻擊；撞牆為 **0.3 秒** |
| 硬質期間被攻擊 | 不會反擊，等硬直結束後的下一次碰撞才算 |

### 3-4 牆壁反彈

- 每幀檢查角色是否超出螢幕邊界
- 若超出：判定撞牆 → 計算牆壁反彈 → 回彈回戰場
- 撞牆硬直時間 +0.1 秒（0.3 秒）

### 3-5 貓咪死亡

- 往反方向**拋物線彈飛**，不受牆壁限制
- 飛出畫面後從戰鬥列表移除（節省記憶體）

### 3-6 快速戰鬥系統

戰鬥開始時先在**邏輯層預先模擬**整場戰鬥：

| 模式 | 行為 |
|------|------|
| 正常模式 | 照事件序列播放完整動畫 |
| 加速模式 | 加快播放動畫 |
| 快速模式 | 直接顯示最終結果 |

三種模式使用**相同事件序列**，保證結果一致。

## 四、貓咪種類

### 角色列表（初版規劃）
牛奶貓、三花貓、忍者貓、賓士貓、大橘貓、黑貓
（未來：蝙蝠貓 等）

### 職業屬性類型

| 類型 | 特性 | 玩法 |
|------|------|------|
| 坦克貓 | 高 HP & 高 Weight | 卡位阻擋，撞牆硬直減少 |
| 刺客貓 | 高 ATK & 高 Speed | 瞬間衝刺、連續撞擊，先手打前排後撤退 |
| 防守貓 | 高 DEF & 中 Weight | 反彈傷害、硬直抗性，保護隊伍 |
| 飛行/跳躍貓 | 中 ATK & 高 Speed | 跳過敵前排，直接撞後排 |
| 元素貓 | 火/水/木屬性加成 | 撞擊附加元素效果，利用相剋 |
| 趣味萌寵貓 | 高 HP & 低 ATK | 趣味技能（如吐泡泡干擾），娛樂/收藏向 |
| 高速貓 | 高 Speed | 先手衝撞，短距離穿透 |
| 反彈貓 | 中高 Weight & 中 ATK | 利用牆壁/敵人排列造成連鎖傷害 |

## 五、強化系統

| 道具 | 用途 | 獲取方式 |
|------|------|---------|
| 貓咪乾糧（Cat Food） | 升級 EXP → 提升 HP / ATK / DEF | 關卡掉落、任務、活動 |
| 貓咪罐頭（Cat Can） | 提升 Weight（附加硬直抗性/撞擊威力） | 關卡中高稀有掉落、日常任務 |
| 貓咪鬍鬚（Cat Shard） | 技能升級 / 升星 / 品階 | 關卡掉落、商店、活動 |
| 特殊技能書 | 解鎖/強化技能（MVP 後加入） | 高難度關卡、活動、商店 |
| 貨幣（金幣） | 購買乾糧、罐頭、碎片、裝備 | 戰鬥獎勵、日常任務、活動 |

> MVP 建議：先做一種乾糧，後續擴充不同種類對應不同屬性成長

## 六、關卡系統

### 關卡格式
```
1-1 → 1-2 → 1-3 → 1-Boss
2-1 → 2-2 → 2-3 → 2-Boss
...
```

- 需先勝過 **3 輪爪牙**，才能挑戰 Boss
- 挑戰 Boss 需玩家手動按下「挑戰 Boss」按鈕
- **自動推關模式**：連續自動打 3 輪爪牙 → Boss → 重複
- 若在某關失敗（例如 2-3），自動挑戰**停在該關**

### 放置/離線獎勵
- 每**分鐘**計算一次獎勵（在線 & 離線皆算）
- 每小時固定 60 個貓咪乾糧 + 隨機道具
- 獎勵量與**當前關卡進度**成正比
- 推進越深，放置收益越高

## 七、主畫面 & UI 結構

### 主畫面（預設畫面）
- 顯示**戰鬥場地**，我方貓咪持續與 Boss 爪牙戰鬥
- 主要按鈕（開啟對應視窗/場景）：

| 按鈕 | 功能 |
|------|------|
| 配置 | 進入貓咪配置畫面 |
| 強化 | 強化貓咪 |
| 商店 | 購買道具 |
| 競技場 | 異步 PvP |
| 聊天室 | 全球聊天 |

- 所有視窗/場景**返回後回到主畫面**

### 配置畫面
- **出戰配置**：拖曳已擁有的貓咪縮圖至上場位置，決定站位順序
  - 長按縮圖：查看主動/被動技能與冷卻時間
- **貓咪圖鑑**：所有擁有的貓咪縮圖
  - 點擊縮圖：查看基礎屬性、主動/被動技能、冷卻時間

## 八、競技場（PvP）

- **異步模式**：打對方的防守隊伍紀錄
- 使用與一般戰鬥相同的模擬系統
- 勝利加分、失敗扣分

### 牌位系統

| 牌位 | 階級 | 晉升條件 |
|------|------|---------|
| 銅牌 | III → II → I | 積分累積 |
| 銀牌 | III → II → I | 積分累積 |
| 金牌 | III → II → I | 積分累積 |
| 白金 | III → II → I | 積分累積 |
| 鑽石 | III → II → I | 積分累積 |
| 大師 | III → II → I | 依全服百分比（PR）計算 |
| 菁英 | — | 全服前 100 名 |

> 例：銅牌 III → 銅牌 II → 銅牌 I → 銀牌 III → ...→ 鑽石 I → 大師

### 大師牌位（PR 計算）

| 牌位 | 條件 |
|------|------|
| 大師 III | PR 0 ～ 50（後 50%） |
| 大師 II | PR 10 ～ 49 |
| 大師 I | PR 1 ～ 9（前 10%） |
| 菁英 | 全服前 100 名 |

## 九、技能系統

### 被動技能
- 戰鬥開始即生效
- 效果：全隊 buff（如冷卻 -10%）或敵方 debuff

### 主動技能
- 每隔 X 秒**自動發動**（玩家無法手動觸發）
- **起始施放時間**在配置畫面設定，流程如下：
  1. 玩家將貓咪拖曳至出戰位置
  2. 貓咪圖示下方顯示技能圖示及**秒數格子**（預設為 0）
  3. 點擊秒數格子 → 彈出 0～9 的數字按鈕
  4. 點選數字即設定首次發動時間（僅支援個位數 0～9 秒）
- 無距離限制
- 硬直期間冷卻繼續計算，但需硬直結束後才能發動
