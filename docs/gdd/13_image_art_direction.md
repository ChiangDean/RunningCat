# 喵喵衝撞派對 圖像創作總規範

最後更新：2026-04-07

## 1. 目的

本文件是《喵喵衝撞派對》未來所有圖片生成、主視覺設計、場景插圖、活動圖、介面背景圖的統一風格依據。

之後只要需要生成圖片，應先讀取本文件，再開始撰寫 prompt 或製作圖像。  
若新需求沒有特別推翻本文件，則一律以本文件為最高優先的美術方向。

## 2. 核心創作理念

《喵喵衝撞派對》的圖像方向，不是夢幻派對，也不是科幻貓咪世界，而是：

- 從貓咪視角觀看的喵星日常世界
- 在人類熟悉的居家空間中，貓咪把每個角落都當成自己的地盤
- 氣氛可愛、休閒、親切、舒服
- 有競爭與衝撞，但不是暴力，而是調皮、熱鬧、帶一點隊伍感

一句話總結：

「這是一個以家為舞台、由貓咪主導、帶有地盤爭奪感的家常像素世界。」

## 3. 世界觀轉譯原則

### 3.1 貓咪才是畫面主角

- 畫面應以貓咪的行動與視角為主。
- 人類不作為主視覺主體。
- 人類存在感只透過居家痕跡表現，例如窗簾、紙箱、地毯、貓碗、玩具、家具角落、陽光照進來的房間。

### 3.2 場景應該像「家中的冒險舞台」

- 客廳
- 窗邊
- 木地板
- 地毯
- 紙箱
- 貓跳台
- 陽台
- 櫃子旁
- 沙發邊

這些都是未來圖像的重要場景來源。

### 3.3 情緒關鍵字

- 居家
- 溫暖
- 自由
- 日常
- 可愛
- 活潑
- 多貓隊伍
- 地盤爭奪

## 4. 主要風格

### 4.1 視覺風格

- 像素風
- 可愛但不幼稚
- 精緻 2D 遊戲主視覺感
- 清楚可讀的造型輪廓
- 溫暖居家，而非糖果派對

### 4.2 風格限制

應避免：

- 過度 chibi
- 偶像海報感
- 日系動畫宣傳海報感
- 過度夢幻童話
- 過度粉嫩糖果色
- 過度科幻或未來風
- 黑暗恐怖風
- 厚重霓虹與賽博風
- 現代 glossy app 宣傳圖風格

## 5. 色系規範

整體應以「家常自然色」為主，而非鮮豔糖果色。

### 5.1 主色系

- 奶油牆面：`#F3EEE2`
- 亞麻米色：`#E8DFCF`
- 淡暖木色：`#D1C1AA`
- 蜂蜜木地板：`#AE8666`
- 深木框色：`#6F5A47`
- 牛皮紙箱棕：`#CFAA7F`
- 灰綠布簾：`#A5B09A`

### 5.2 輔助色

- 窗光淡金：`#FFF6E7`
- 玻璃灰藍：`#DCE8EA`
- 地毯奶棕：`#B38768`
- 貓碗灰青：`#8DA2A1`
- 淡毛色橘棕、乳白、灰黑、卡其

### 5.3 顏色原則

- 可以溫暖，但不要高飽和刺眼
- 可以可愛，但不要整張偏粉
- 應讓人聯想到日光、木頭、布料、紙箱、貓毛
- 若需要亮點色，優先從自然暖色中選擇，而不是螢光色

## 6. 構圖規範

### 6.1 行動裝置直式圖優先

本專案首頁、活動圖、主視覺背景，預設優先考慮直式手機比例。

推薦：

- 1024x1536
- 或其他近似直式比例

### 6.2 留白原則

圖片不應被主體塞滿。  
需要保留給遊戲 UI 疊加的安全區域。

常用分區：

- 上半部：環境氛圍、窗景、空氣感、標題安全區
- 中段：主視覺與故事焦點
- 下半部：角色運動區、按鈕安全區

### 6.3 構圖重點

- 主角貓咪群應放在畫面中段或下半部偏中間
- 上方環境應有足夠空間放標題
- 下方應預留互動按鈕或提示文字的位置
- 背景可以豐富，但不能搶過主角貓咪

## 7. 角色表現規範

### 7.1 貓咪不是靜態擺拍

未來圖片中的貓咪，優先表現成：

- 雙腳小跑步
- 一起往前衝
- 彼此像隊伍一樣移動
- 有活力、有方向感
- 帶一點搶地盤的競爭感

### 7.2 建議角色群像

優先使用：

- 2 到 4 隻貓咪同時出現
- 毛色有差異，形成辨識度
- 表情可愛、開朗、有精神

避免：

- 只出現單一大頭
- 過度誇張表情包
- 太像貼圖素材

## 8. 光線與氛圍

### 8.1 優先光線

- 午後窗光
- 柔和室內漫射光
- 溫暖日常照明

### 8.2 氛圍方向

- 舒服
- 親切
- 活潑
- 放鬆
- 居家

不要做成：

- 夜店派對
- 霓虹舞台
- 緊張恐怖
- 冷調科幻

## 9. 材質與細節

生成圖片時，應優先強化以下材質感：

- 像素木紋
- 編織地毯
- 柔布窗簾
- 紙箱表面
- 貓毛的溫暖柔和色塊
- 簡單但可辨識的日用品

材質應該：

- 有像素風辨識度
- 不需要過度寫實
- 要讓玩家一眼知道這是熟悉的家居空間

## 10. 禁止方向

未來所有圖片若無特殊活動需求，應避免以下方向：

- neon
- candy palette
- sci-fi look
- dark horror mood
- glossy modern app style
- heavy idol poster composition
- over-chibi mascot style
- dark cyberpunk purple-blue tone

## 11. 首頁主圖基準案例

這次首頁圖的創作方向，視為未來圖片風格的第一個基準案例。

### 11.1 創作定位

- 用途：手機遊戲首頁背景圖
- 類型：直式主視覺背景
- 風格：家常像素風
- 主題：貓咪在家中集結、衝撞、搶地盤

### 11.2 關鍵畫面元素

- 溫暖公寓室內
- 陽光從窗邊灑入
- 柔布窗簾
- 木地板
- 地毯
- 紙箱
- 貓碗
- 多隻貓咪用雙腳小跑步
- 有隊伍感與衝刺感

### 11.3 首頁圖應達成的效果

- 一眼看出是貓咪主角遊戲
- 一眼看出是家中世界，不是奇幻宇宙
- 一眼看出畫面可以放標題與開始按鈕
- 給人可愛、舒服、願意進入遊戲的感覺

## 12. 首頁圖片原始生成 Prompt

以下 prompt 視為首頁圖片生成基準稿，未來可在此基礎上延伸：

```text
Use case: stylized-concept
Asset type: mobile game start screen background illustration
Primary request: a cozy home interior seen from a cat's-eye view, designed as a cute pixel-art game start screen background for a cat battle game

Scene/backdrop: warm apartment interior with a sunlit window, soft curtain, wood floor, rug, cardboard box, cat bowl, and lived-in home details that cats would notice

Subject: three cute cats running upright on two legs as a team across the room, playful and energetic, as if racing to claim territory inside the house

Style/medium: charming pixel-art illustration, clean readable shapes, polished 2D game key art, family-friendly, not overly chibi, not anime poster style

Composition/framing: vertical mobile composition, centered action area with open space for title and start button overlay, cats in the lower-middle zone, window and room atmosphere in upper zone

Lighting/mood: warm afternoon window light, cozy domestic feeling, cheerful and relaxed, everyday home life rather than fantasy party

Color palette: homey natural palette, cream wall, linen beige, soft gray-green curtain, honey wood floor, cardboard brown, muted cat fur colors; avoid bright pink dominance

Materials/textures: pixel-art wood grain, woven rug feel, soft curtain fabric, cardboard box texture, simple readable household props

Constraints: no text, no logos, no watermark, no UI frame, suitable as a background image for a Godot game title screen, keep it cute and domestic, emphasize multiple cats and a home setting

Avoid: neon colors, candy palette, sci-fi look, dark horror mood, glossy modern app style
```

## 14. 各頁面延伸方向

### 14.1 商店頁

- 像家中的零食櫃、紙箱堆、囤貨角落、玩具籃
- 風格仍以居家和暖色材質為主

### 14.2 抽卡頁

- 像拆箱、翻紙箱、罐罐補給、神秘居家角落發現戰利品
- 可以有驚喜感，但不能變成科幻召喚

### 14.3 養成頁

- 像窗邊小窩、貓房、收藏牆、舒服的休息區
- 比首頁更偏陪伴與收集感

### 14.4 戰鬥或地盤爭奪頁

- 可以更有動感
- 但環境仍應來自生活場域
- 例如客廳、走廊、陽台、屋頂、庭院
