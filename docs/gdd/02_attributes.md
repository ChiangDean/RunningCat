# 二、貓咪屬性

每隻貓咪擁有以下基礎數值：

| 屬性 | 說明 |
|------|------|
| MaxHP | 最大血量 |
| CurrentHP | 當前血量 |
| ATK | 攻擊力，決定對敵方造成的傷害 |
| DEF | 防禦力，採**遞減式減傷**，無限堆疊不會超過上限減傷率 |
| Speed | 左右橫移速度 |
| Weight | 重量，決定撞擊後回彈距離 |
| 被動技能 | 全隊 buff、敵方 debuff，戰鬥開始即生效 |
| 主動技能 | 每隔 X 秒自動發動，玩家可設定起始施放時間點 |

## DEF 減傷公式

```
減傷率 = DEF / (DEF + 100)
```

| DEF 值 | 減傷率 |
|--------|--------|
| 0 | 0% |
| 50 | 33.3% |
| 100 | 50% |
| 200 | 66.7% |
| 300 | 75% |
| 400 | 80% |
| 900 | 90% |

- 遞減設計讓堆疊防禦邊際效益下降，永遠不會達到 100% 減傷
- 未來可加入「無視防禦」效果，直接削弱對方 DEF 計算值
