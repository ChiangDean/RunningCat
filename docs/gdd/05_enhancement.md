# 五、強化系統

## 5-1 道具總覽

| 道具 | 用途 | 獲取方式 |
|------|------|---------|
| 普通乾糧 | 自動升級全屬性（HP / ATK / DEF） | 關卡掉落、任務、活動 |
| 特殊乾糧 | 自由分配點數給 HP / ATK / DEF | 關卡掉落、任務、活動 |
| 貓咪罐頭 | 提升 Weight（未來實作） | 關卡高稀有掉落 |
| [貓名]鬍鬚碎片 | 升品階，各貓有專屬碎片 | 誘捕重複、關卡掉落 |
| 金幣 | 購買道具（未來實作） | 戰鬥獎勵、日常任務 |
| 鑽石 | 誘捕籠、重置強化費用 | 活動、課金 |
| 誘捕點數 | 商店兌換道具 | 品階滿後重複貓咪轉換 |

## 5-2 普通乾糧升級

- 等級從 Lv.1 起算，系統上限 **Lv.30**（未來可突破）
- 升一級自動提升 HP / ATK / DEF（依各貓 Config `enhancement_growth`）
- **費用：** `cost(lv) = (lv + 1)²`

| 等級 | 費用 |
|------|------|
| Lv.1 → 2 | 4 |
| Lv.2 → 3 | 9 |
| Lv.N → N+1 | (N+1)² |

### UI
- `升級(持有/費用)` — 乾糧不足時 disabled
- `快速升級(LvN 持有/總費用)` — 計算目前乾糧可達最高等級；乾糧不足升一級時 disabled

## 5-3 特殊乾糧分配

- 玩家自由分配點數給 HP / ATK / DEF
- 第 n 點（0-based）費用：`n + 1`（n = 全部屬性的總已分配點數）
- 累計已消耗：`n*(n+1)/2`
- **退點**：退還費用 = 退點前的總點數（即最後一點的花費）

| 已分配（n） | 下一點費用 | 累計消耗 |
|-----------|---------|--------|
| 0 | 1 | 0 |
| 1 | 2 | 1 |
| 2 | 3 | 3 |
| n | n+1 | n*(n+1)/2 |

### UI
- 整合在屬性列，每條屬性右方顯示 `−` / 已分配點數 / `+`
- `+` 在乾糧不足時 disabled；`−` 在該屬性點數為 0 時 disabled
- 上方顯示：`特殊乾糧下一點費用：N（持有 M）`

## 5-4 屬性成長值（Config 設定，各貓不同）

| 貓咪 | HP/點 | ATK/點 | DEF/點 |
|-----|------|--------|--------|
| 牛奶貓 | +2.0 | +0.5 | +1.5 |
| 其他（預設） | +1.5 | +1.0 | +0.5 |

## 5-5 屬性顯示格式

- 屬性欄顯示**最終值**（含普通乾糧 + 特殊乾糧 + 品階加成），不另行標注各加成來源
- 品階加成最後計算：`final = int((base + food_bonus + special_bonus) × (1 + rank × percent / 100))`

```
HP:  1050
ATK: 165
DEF: 83
```

## 5-6 品階系統

- 消耗各貓**專屬鬍鬚碎片**（`cat_shards`）提升品階，**無上限**
  - 例：牛奶貓消耗「牛奶貓鬍鬚碎片」、黑貓消耗「黑貓鬍鬚碎片」
- 升至品階 N 費用：`N × 20` 片（+1:20, +2:40, +3:60...）
- 貓咪名字旁顯示星星：`★×N`（品階 0 不顯示）
- **每階屬性加成**（依 Config `rank_growth`，各貓可不同，預設）：
  - HP / ATK / DEF 各 **+1%**（最後套用在所有加成之上）
- **每 5 階**：技能效果等級 **+1**（技能欄顯示 `+N`，品階 < 5 不顯示）

### UI
- 升階按鈕：`升階(持有/需求)`，碎片不足時 disabled
- `?` 按鈕顯示當前加成說明：「血量、攻擊、防禦額外提升 N%」

## 5-7 重置機制

- 全部素材完整退回，目前費用 **0 鑽石**
- 退回計算：
  - 普通乾糧：`Σ (n+1)²` for n in [1, level-1]
  - 特殊乾糧：`n*(n+1)/2`（n = 已分配總點數）
- 品階**不重置**（碎片已消耗）

## 5-8 UI 流程

```
強化主畫面 → 選貓咪 → 詳細面板
  ├─ 名字列：[貓咪名] [★×N] [?] ────── [升階(持有/需求)]
  ├─ 屬性（含特殊乾糧控制）
  │    特殊乾糧下一點費用：N（持有 M）
  │    HP: 1050    [−] [pts] [+]
  │    ATK: 165    [−] [pts] [+]
  │    DEF: 83     [−] [pts] [+]
  ├─ 普通乾糧升級
  │    [升級(持有/費用)]  [快速升級(LvN 持有/總費用)]
  ├─ 技能（品階 ≥ 5 時顯示技能等級 +N）
  └─ [重置（確認視窗）]
```
