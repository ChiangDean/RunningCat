# 五、強化系統

## 5-1 道具總覽

| 道具 | 用途 | 獲取方式 |
|------|------|---------|
| 普通乾糧 | 自動升級全屬性（HP / ATK / DEF） | 關卡掉落、任務、活動 |
| 特殊乾糧 | 自由分配點數給 HP / ATK / DEF | 關卡掉落、任務、活動 |
| 貓咪罐頭 | 提升 Weight（未來實作） | 關卡高稀有掉落 |
| 鬍鬚碎片 | 升品階（未來：技能升級） | 誘捕重複、關卡掉落 |
| 金幣 | 購買道具（未來實作） | 戰鬥獎勵、日常任務 |
| 鑽石 | 誘捕籠、重置強化費用 | 活動、課金 |
| 誘捕點數 | 商店兌換道具 | 品階滿後重複貓咪轉換 |

## 5-2 普通乾糧升級

- 等級從 Lv.1 起算，系統上限 **Lv.30**（未來可突破）
- 升一級自動提升 HP / ATK / DEF（依各貓 Config `enhancement_growth`）
- **費用：** `cost(lv) = (lv + 1)²`

| 等級 | 費用 |
|------|------|
| Lv.1 → 2 | 4 |
| Lv.2 → 3 | 9 |
| Lv.N → N+1 | (N+1)² |

## 5-3 特殊乾糧分配

- 玩家自由分配點數給 HP / ATK / DEF
- 第 n 點（0-based）費用：`n + 1`
- 累計已消耗：`n*(n+1)/2`

| 已分配（n） | 下一點費用 | 累計消耗 |
|-----------|---------|--------|
| 0 | 1 | 0 |
| 1 | 2 | 1 |
| 2 | 3 | 3 |
| n | n+1 | n*(n+1)/2 |

## 5-4 屬性成長值（Config 設定，各貓不同）

| 貓咪 | HP/點 | ATK/點 | DEF/點 |
|-----|------|--------|--------|
| 牛奶貓 | +2.0 | +0.5 | +1.5 |
| 其他（預設） | +1.5 | +1.0 | +0.5 |

## 5-5 屬性顯示格式

```
HP:  1002 +4    ← 基礎+普通乾糧 / 特殊乾糧附註
ATK: 150        ← 無特殊加成時不顯示
DEF: 53 +3
```

## 5-6 品階系統

- 消耗**鬍鬚碎片**提升品階，**無上限**
- 升至品階 N 費用：`N × 20` 片（1階:20, 2階:40, 3階:60...）
- 圖示右上顯示：`+1`、`+2`、`+3`...
- **每階加成**（依 Config `rank_growth`，各貓可不同，預設）：
  - HP / ATK / DEF 各 **+1%**
- **每 5 階**：技能效果 **+10%**

## 5-7 重置機制

- 全部素材完整退回，目前費用 **0 鑽石**
- 退回計算：
  - 普通乾糧：`Σ (n+1)²` for n in [1, level-1]
  - 特殊乾糧：`n*(n+1)/2`（n = 已分配總點數）

## 5-8 UI 流程

```
強化主畫面 → 選貓咪 → 詳細面板
  ├─ 屬性顯示（基礎 + 普通加成 + 特殊附註）
  ├─ 普通乾糧升級（[升級] / [一鍵升至 Lv.30 → 確認視窗]）
  ├─ 特殊乾糧分配（HP/ATK/DEF 各 [+]，直接扣）
  └─ [重置（確認視窗）]
```
