## 5-8 UI 補充（2026-04-13）
- 強化主頁改為共用圖卡與共用子選單結構，`ConfigScene`、`ScooperScene`、`EnhanceScene` 使用同一套子選單 builder；圖卡樣式也抽成共用元件。
- 強化主頁的貓咪列表改為圖卡式顯示，不顯示名稱，圖卡會顯示 `等級`、`品階` 資訊；強化頁可直接點整張圖卡開啟細部強化 Dialog。
- 細部強化改為 Dialog 形式，內容加入卷軸拖曳與 tab 切換，分為 `等級`、`技能`、`品階` 三個頁籤。
- 細部強化 Dialog 需提供 `能力總覽`，分成 `基礎能力` 與 `加成後` 兩頁；基礎能力對齊後端 cat catalog seed 的 HP / ATK / DEF / Speed / Weight / Crit / Evasion / Accuracy / Multi-hit 等欄位，加成後能力需套用等級、特殊乾糧、品階、鏟屎官裝備、記憶、寶物與被動技能；被動技能名稱與能力欄位以後端 `StatTypeEnum` / bootstrap 輸出的 stat id 為準，例如「無視防禦」顯示並計入 `armor_pen` 護甲穿透；加成後能力不逐條列出裝備 / 記憶 / 寶物來源明細。
- `能力總覽` 每個能力列右側需提供說明按鈕，解釋該能力的實際用途與目前數值推導，例如防禦需顯示目前 DEF 對應的物理減傷比例，暴擊率需說明 1.5 倍基礎暴擊傷害與超過 100% 的溢出解讀。
- 細部強化第一區塊上方改為素材列，顯示 `普通乾糧 / 特殊乾糧 / 貓咪鬍鬚` 數量。
- `等級` 頁籤顯示 EXP 讀條，條內文字格式為 `EXP 持有/需求`；未達標、可升級、滿級三種狀態使用不同樣式。
- `品階` 頁籤顯示升階讀條，條內文字格式為 `持有/需求`，並與 EXP 讀條共用同高度與樣式規則。
- 特殊乾糧屬性分配改為前端草稿模式，按 `+` 時先做本地預覽，不會每次點擊就立即送出後端。
- 屬性列固定顯示目前累積效果，格式為 `生命：534 +1 (4.2)`，其中 `+1` 代表已配置點數，括號內為實際加成值。
- `下一點消耗特殊乾糧` 改為即時預覽格式 `3 (3/33)`，分別代表下一點消耗與目前持有量。
- 屬性區底部新增 `套用屬性變更` 按鈕，只有草稿有變更時才可按下；送出時會一次套用目前全部變更。
- 屬性區底部新增 `重置` 按鈕，會將目前這隻貓已配置的全部屬性點數歸零，並返還已投入的特殊乾糧；若仍有未套用草稿，也會一併清除。
- `升級`、`快速升級`、`升階`、`重置` 都改為共用按鈕色票；按下升級或升階後會顯示浮動文字回饋。
