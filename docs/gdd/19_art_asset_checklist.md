# 十九、美術素材正式清單

最後更新：2026-04-11

## 1. 文件目的

本文件整理《喵喵衝撞派對》目前應優先準備的美術素材種類，作為製作排程、AI 製圖、委外發包與整合檢查的統一清單。

本清單不拆分個別貓咪，而是列出共通資產種類。  
若之後新增頁面或系統，可在本文件追加項目。

- [13_image_art_direction.md](13_image_art_direction.md)
- [17_art_asset_production_spec.md](17_art_asset_production_spec.md)
- [18_ai_art_prompt_pack.md](18_ai_art_prompt_pack.md)

## 2. 優先級定義

- `P0`：沒有就會直接影響上線或基本可玩性
- `P1`：強烈建議補齊，會直接影響完整度與品質
- `P2`：可後補，主要提升包裝感與延伸性

## 7. 每項素材應記錄的欄位

未來新增任一素材時，建議至少補以下資訊：

| 欄位 | 說明 |
|------|------|
| Asset name | 素材名稱 |
| Category | 動畫 / 靜態 / 背景 / UI |
| Use case | 使用頁面與功能 |
| Priority | P0 / P1 / P2 |
| Canvas size | 原始畫布尺寸 |
| Background | 透明 / 不透明 |
| Safe area | 需避讓區域 |
| In-game visible size | 遊戲內預估顯示大小 |
| Cropping allowed | 是否允許裁切 |
| Flip allowed | 是否允許左右翻轉 |
| Source method | AI / 手繪 / 像素重修 / 混合 |
| Status | 未開始 / 製作中 / 已完成 / 已整合 |
| Notes | 其他限制 |

## 10. 管理原則

- 同類素材盡量共用尺寸規格
- 若一期資源不足，優先做可共用的共通動畫
- 若 AI 成果不穩，優先先產出大圖，再做像素修整與切圖
- 所有背景圖都要先檢查是否壓到 UI 安全區
- 所有小圖示都要在縮小後檢查一次可讀性

本文件可作為後續排程表、委外清單或 AI 製圖工作單的母表。
