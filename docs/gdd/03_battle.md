# 三、戰鬥系統

## 3-1 陣型配置

```
[ 我方隊伍 ]                    [ 敵方隊伍 ]
Cat5 Cat4 Cat3 Cat2 Cat1  →←  Cat1 Cat2 Cat3 Cat4 Cat5
                    碰撞區
```

- 我方：左側，面朝右；Cat1 在最右（前排）
- 敵方：右側，面朝左；Cat1 在最左（前排）
- 前排起始位置保留開場距離：我方 Cat1 約在 x=220，敵方 Cat1 約在 x=500，避免一開場立即碰撞扣血。
- 同隊不碰撞，對方互相碰撞
- **最大上場數：由 config 設定（預設 5 隻，可調整）**
    最大上場數、隊伍限制等皆可於 JSON 設定檔（如 boss_config.json、dungeon_config.json、arena_config.json）調整，遊戲會自動讀取。

## 3-2 戰鬥流程

1. **倒數 60 秒**開始
2. 雙方所有存活貓咪往中間移動
3. 前排接觸 → **碰撞判定**
4. 計算傷害、回彈距離、硬直時間
5. 技能冷卻時間到 → **自動發動**
6. 貓咪死亡 → 拋物線彈飛出畫面
7. 60 秒內消滅全部敵方 → **勝利**；否則 → **失敗**

## 3-3 碰撞計算

| 計算項目 | 說明 |
|---------|------|
| 傷害 | ATK 對方 DEF 減傷後扣血 |
| 回彈距離 | 基礎回彈 200px，再加上雙方 Weight 差 × 20px；最小 0px、最大 500px |
| 硬直時間 | 碰撞後 0.2 秒；撞牆額外增加 2 秒 |

- 衝撞傷害使用目前 runtime 數值，不直接讀靜態基礎值：`ATK`、`ATK%`、`DEF`、`DEF%`、`ArmorPen`、`DamageReduction`、`CritRate`、`CritDamage`、`Evasion`、`Accuracy`、`MultiHitRate`、`MultiHitDamage`、`CounterDamageChance`、技能 buff / debuff、裝備、記憶、寶物都需在計算前合併。
- DEF 減傷公式：`effectiveDef = DEF × (1 - ArmorPen)`，`defReduction = effectiveDef / (effectiveDef + 100)`，基礎傷害為 `max(1, ATK × (1 - defReduction))`。
- 閃避判定：`Evasion - Accuracy`，最小 0%，最高 75%；成功閃避時該次攻擊傷害為 0。
- 暴擊率最高 100%；超過 100% 的暴擊率不再提高觸發率，改為等量轉換成暴擊傷害加成。暴擊倍率為 `1.5 + CritDamage + max(0, CritRate - 1.0)`。
- 連擊率最高 75%；連擊觸發時追加 1 次額外傷害，額外傷害倍率為 `50% + MultiHitDamage`。連擊只增加傷害，不新增碰撞擊退事件。
- 反傷機率（`CounterDamageChance`）觸發時，該次原本承受的傷害由受擊者承受 50%，攻擊者承受 50%。技能型反擊 / 反傷則依技能 `value` 將實際承受傷害反彈給攻擊者。
- 碰撞判定以戰鬥角色視覺寬度約 96px 為基準；兩方中心距離小於等於 96px 時視為前緣接觸。
- 每次碰撞只檢查雙方目前最前排角色；後排角色不會穿過前排去碰撞對方第二排。
- 正式戰鬥以畫面 runtime 位置作為碰撞來源；角色實際跑到接觸點時才計算碰撞、傷害、擊退、死亡與勝負。`BattleSimulator` 僅保留為開發快速模擬工具，不作為正式畫面戰鬥的事件來源。
- 碰撞撞飛時，角色以自身原速 10 倍作為初速，線性減速到 0；撞飛停下後再花 1 秒從 0 線性加速回原本移動速度。
- 角色處於碰撞硬直期間時，不會造成新的碰撞攻擊傷害；但仍會被非硬直對手的碰撞攻擊命中。硬直不會讓角色暈眩停住，角色仍會依照擊退位移與移動速度繼續走動。
- 若攻擊者這次碰撞會造成對手撞到牆壁，攻擊者會觸發反撞：退後距離參考這次對手的一般回彈距離 ×2，最少 100px，最多退到牆壁；拋物線高度同樣參考一般回彈距離 ×2，最少 200px、最高 400px；翻滾一圈，0.6 秒後落回平面並進入原本的回復加速流程。
- 撞到牆壁者仍會進入撞牆硬直；但撞牆硬直結束後不再從 0 重新加速，會直接以原本完整移動速度繼續前進。

## 3-4 牆壁反彈

- 超出螢幕邊界 → 撞牆 → 回彈，追加撞牆硬直 2 秒

## 3-5 快速戰鬥系統

戰鬥開始時先**邏輯層預先模擬**整場，三種模式使用相同事件序列，保證結果一致：

| 模式 | 行為 |
|------|------|
| 正常模式 | 照事件序列播放完整動畫 |
| 加速模式 | 加快播放動畫 |
| 快速模式 | 直接顯示最終結果 |
