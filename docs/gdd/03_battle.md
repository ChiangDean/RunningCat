# 三、戰鬥系統

## 3-1 陣型配置

```
[ 我方隊伍 ]                    [ 敵方隊伍 ]
Cat5 Cat4 Cat3 Cat2 Cat1  →←  Cat1 Cat2 Cat3 Cat4 Cat5
                    碰撞區
```

- 我方：左側，面朝右；Cat1 在最右（前排）
- 敵方：右側，面朝左；Cat1 在最左（前排）
- 同隊不碰撞，對方互相碰撞
- **最大上場數：由 config 設定（預設 5 隻，可調整）**
    最大上場數、隊伍限制等皆可於 JSON 設定檔（如 boss_config.json、dungeon_config.json、arena_config.json）調整，遊戲會自動讀取。

## 3-2 戰鬥流程

1. **倒數 60 秒**開始
2. 雙方所有存活貓咪往中間移動
3. 前排接觸 → **碰撞判定**
4. 計算傷害、回彈距離、硬直時間
5. 技能冷卻時間到 → **自動發動**
6. 貓咪死亡 → 拋物線彈飛出畫面
7. 60 秒內消滅全部敵方 → **勝利**；否則 → **失敗**

## 3-3 碰撞計算

| 計算項目 | 說明 |
|---------|------|
| 傷害 | ATK 對方 DEF 減傷後扣血 |
| 回彈距離 | 由雙方 Weight 差決定；基礎回彈 200px，設有最短/最長回彈上限 |
| 硬直時間 | 碰撞後 0.2 秒；撞牆為 0.3 秒 |

- 碰撞回彈結束後，角色會花 1 秒從 0 線性加速回原本移動速度。

## 3-4 牆壁反彈

- 超出螢幕邊界 → 撞牆 → 回彈，硬直 +0.1 秒（共 0.3 秒）

## 3-5 快速戰鬥系統

戰鬥開始時先**邏輯層預先模擬**整場，三種模式使用相同事件序列，保證結果一致：

| 模式 | 行為 |
|------|------|
| 正常模式 | 照事件序列播放完整動畫 |
| 加速模式 | 加快播放動畫 |
| 快速模式 | 直接顯示最終結果 |
