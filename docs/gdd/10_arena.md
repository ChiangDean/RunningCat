## 積分變化規則

| 對手段位 | 勝利 | 失敗 |
|---------|------|------|
| 高於自己 | +21 ~ +30 | -5 ~ -10 |
| 同段位 | +10 ~ +20 | -10 ~ -20 |
| 低於自己 | +5 ~ +10 | -21 ~ -30 |

- **連勝 / 連敗**：每場額外 ±1 分（斷連則回歸基本分，不累加）

## 賽季系統

- 賽季長度：約一個月（由 Config 設定 `season_end_date`）
- 遊戲開啟時比對本機日期，超過則自動觸發賽季重置
- **賽季重置降段規則**：

| 原段位 | 重置後 |
|--------|--------|
| 菁英 / 大師 | 鑽石 III（積分 1200） |
| 鑽石 | 金牌 III（積分 600） |
| 白金 | 銀牌 III（積分 300） |
| 金牌 以下 | 銅牌 III（積分 0） |

## 競技券系統

- 每日免費贈送 **10 張**競技券
- 可花費鑽石額外購買，每次購買 **3 張**，每天最多購買 **5 次**

| 第幾次購買 | 花費鑽石 |
|-----------|---------|
| 第 1 次 | 100 |
| 第 2 次 | 150 |
| 第 3 次 | 200 |
| 第 4 次 | 250 |
| 第 5 次 | 300 |

> 以上數值可由 Config 設定

## 對手選取系統

- 隨機列出 **3 個**同段位附近對手（顯示其防守陣容）
- 若同段位不足，自動擴大範圍搜尋
- **重骰按鈕**：重新隨機選取對手，按下後 **5 秒冷卻**（按鈕 grey out + 數字倒數），本輪已出現的對手不會重複

## 隊伍設定

- **防守隊伍**：於競技場主頁設定，最多 5 隻貓
- 若未設定防守隊伍，自動代入攻擊隊伍
- 攻擊隊伍與防守隊伍儲存於 `player_data.json`（與其他玩家資料並列）

## 玩家資料

### player_arena.json 內容
竸技場專屬存檔，參考 `player_dungeons.json` 的模式：
- `player_id`：玩家唯一識別碼
- `player_name`：玩家名稱（預設「測試玩家」+ 隨機編號，支援多語言與符號）
- `score`：當前積分
- `tickets`：競技券剩餘張數
- `daily_purchase_count`：今日已購買競技券次數（每日重置）
- `win_streak`：當前連勝數
- `loss_streak`：當前連敗數
- `claimed_rank_rewards`：已領取的段位獎勵清單（Array of rank keys）
- `last_reset_date`：上次每日重置日期（UTC+8，YYYY-MM-DD）
- `season_end_date`：當前賽季結束日期（由 Config 設定，遊戲啟動時比對）

**不儲存**隊伍陣容（存於 `player_data.json`）

### arena_data.json 內容（排行榜）
所有玩家（含假玩家）的積分索引，以 Dictionary 儲存，key 為 `player_id`：

```json
{
  "player_001": { "score": 45 },
  "fake_001":   { "score": 80 }
}
```

- O(1) 查找，直接以 `player_id` 取得積分
- 真實玩家積分隨對戰動態更新；假玩家積分固定
- 未來連線時此檔案由 server-side API 取代，`player_arena.json` 結構不變

### 對手資料查詢流程
1. 從 `arena_data.json` 依積分接近程度篩選同牌位候選對手的 `player_id`
2. 以 `player_id` 查詢對應存檔（真實玩家查 `player_data.json`、假玩家查 `fake_players/`）取得名稱、防守隊伍、積分

- 名稱支援多語言
