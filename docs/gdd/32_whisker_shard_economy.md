# 32. 鬍鬚碎片（升階）經濟設計

> Last updated: 2026-04-29

對應後端 GDD：`MeowPartyDashAPI/gdd/whisker_shard_economy_design.md`

## 1. 核心設定

| 設定 | 值 | 說明 |
|-----|---|------|
| 地下城 base_reward_amount | 2 | 每次清關最低保底碎片 |
| 地下城 whisker_shard_divisor | 3 | 每 3 層 +1 碎片 |
| 升階費用公式 | `N × 20` | 升到 Rank N 的單次費用 |
| 升階上限 | **無上限** | rank 可無限成長 |

**地下城每次清關碎片**：

```
每次清關 = 2 + round(floor / 3 + 0.5)
```

**升階累計費用**：

```
累計費用（Rank 0 → Rank N）= 10 × N × (N+1)
```

## 4. 升階效果（每 Rank 成長）

- HP / ATK / DEF 各 +1%（依 `cat_data.rank_growth`）
- 每 5 Rank：技能效果 +10%

## 6. 節奏感設計

| 階段 | 日產量 | 升階週期 | 體驗 |
|-----|-------|---------|------|
| 前期 Day 1–20 | 24–152 | 每 2–4 天升一階 | 正向回饋強，快速成長 |
| 中期 Day 20–60 | 152–400 | 每 3–5 天升一階 | 維持動力，均攤 vs 集中策略選擇 |
| 後期 Day 60–90+ | 400–580 | 每 2–3 天升一階 | 長期目標感，高 rank 費用重但產量也高 |
