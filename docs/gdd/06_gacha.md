## 6-4 保底機制（預留，目前無保底）

**機制 A：同品階內特定貓咪機率加倍**
- 活動期間：指定貓咪在其品階中機率 ×N 倍，其他貓咪平分剩餘

**機制 B：M 抽內必出指定貓咪（限 N 次）**
- 活動期間：在 M 抽內保證出現指定貓咪，最多觸發 N 次

## 6-5 重複貓咪處理

重複抽到已擁有的貓咪，依稀有度給予**誘捕點數**：

| 稀有度 | 誘捕點數 |
|--------|---------|
| Common（普通）    | 2 點   |
| Rare（優良）      | 6 點   |
| SuperRare（稀有） | 20 點  |
| UltraRare（超稀有）| 60 點 |
| Special（特別）   | 200 點 |

## 6-6 誘捕點數（Trap Points）兌換

兌換設定由**商店**管理，詳見商店 GDD。

## 6-7 每日免費誘捕

- 機率與一般誘捕**相同**（依技術等級）
- 每次成功使用後，下次免費抽數 **+1**
- 未使用當天：抽數**不增加、不重置**
- 抽數上限由 **Config 設定**（預設 1 抽）

| 操作紀錄 | 免費抽數 |
|---------|---------|
| 第 1 天使用 | 1 抽 |
| 第 2 天使用 | 2 抽 |
| 第 3 天未使用 | — |
| 第 4 天使用 | 3 抽 |
