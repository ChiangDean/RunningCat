帳號刪除說明

本頁說明喵喵衝撞派對（Meow Party Dash!）目前的刪帳號流程、刪除後效果，以及正式上架前仍必須補齊的私人刪帳申請管道。

最後更新：2026-04-23

目前仍未完成的送審項目

  • 私人刪帳申請管道：待補。Google Play 與 App Store 送審前，必須提供不需重新下載 App 也能提出刪除請求的私人渠道，例如正式客服信箱或私密表單。
  • 正式客服信箱：待補。正式上架前，不能只依賴公開 GitHub Issues 處理帳號與個資請求。

1. 誰可以申請刪除帳號

只要您建立過喵喵衝撞派對帳號，就可以申請刪除帳號與相關資料。

目前 App 內已提供刪除帳號入口；若玩家無法登入 App，正式上架前仍需補齊可在網站上完成請求的私人管道。

2. 目前已實作的刪帳號流程

  1. 玩家可在 App 內設定中心發起刪除帳號。
  2. 後端會撤銷該帳號的 refresh token 與登入 session。
  3. 帳號會被標記為刪除狀態，並停止再次登入。
  4. 後續請求會因帳號狀態失效而被擋下。

這部分已對應到目前專案中的 DELETE /api/profile/me 與 active-user session middleware。

3. 刪除後通常會處理的資料

  • 帳號識別資料
  • 玩家個人檔案資料
  • 登入 session 與 refresh token
  • 與該帳號直接關聯的遊戲資料

若資料已進入備份、稽核紀錄或與其他玩家互動內容相關，可能無法立即完全物理刪除；我們會在法律允許與技術可行的範圍內刪除、去識別化，或限制後續使用。

4. 可能保留的資料

  • 資訊安全與防弊調查資料
  • 稽核、觀測性與錯誤排查紀錄
  • 法律、稅務、會計或爭議處理所需資料
  • 備份系統中的短期殘留資料

5. 已購買內容與平台訂閱

刪除遊戲帳號不一定會自動取消 Apple 或 Google 的平台訂閱。若未來版本啟用平台內購或訂閱，玩家仍需先到對應平台管理頁面確認訂閱狀態。

目前專案 demo 路線下，正式 IAP / Billing 尚未上線；這部分仍屬送審前待補項目。
