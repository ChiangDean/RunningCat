2. 不建議公開提交的內容

請不要在 GitHub Issues 或其他公開頁面張貼下列資訊：

  • 帳號資料、登入憑證、裝置識別資訊
  • 支付資訊、訂單細節、退款資料
  • 刪帳號請求、隱私權請求、身分驗證資料
  • 其他可能涉及個資或安全的內容

這類需求需要正式私人客服信箱或私密表單處理，該渠道目前仍待補齊。
