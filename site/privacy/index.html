喵喵衝撞派對 隱私權政策

本頁說明喵喵衝撞派對（Meow Party Dash!）如何處理帳號、玩家個人檔案、遊戲進度、郵件、聊天與安全相關資料，以及玩家如何行使刪帳號與隱私相關權利。

  • 正式客服信箱：待補。上架 Google Play / App Store 前必須補上可收信的私人支援信箱。

1. 適用範圍

本政策適用於喵喵衝撞派對（Meow Party Dash!）遊戲 App、官方 GitHub Pages 網站、支援頁、隱私政策頁、帳號刪除頁，以及玩家透過遊戲或網站所提交的相關資料。

某些功能可能依版本、地區或平台而停用。若功能未啟用，例如 demo 版停用外部登入或付費功能，我們不會因該功能額外蒐集對應資料。

2. 我們蒐集的資料類型

帳號與驗證資料

  • 帳號識別資料、登入識別碼
  • 密碼雜湊與登入安全資料
  • refresh token、登入時間、撤銷時間、裝置 ID / 裝置名稱、登入來源 IP
  • 外部登入綁定狀態與 provider subject，例如 Google、Apple、LINE

玩家個人檔案資料

  • display name、player name、player public id
  • avatar id、bio、birthday、gender type、region

遊戲與社交資料

  • 遊戲進度、背包、裝備、成就、記憶、貨幣與錢包快照
  • 郵件、獎勵信、好友贈禮、好友申請與好友關係資料
  • 聊天訊息內容、頻道閱讀狀態、未讀計數
  • 兌換碼兌換紀錄、商店與購買紀錄（若該版本有啟用）

維運與安全資料

  • API path、HTTP method、status code、request id、trace id、延遲時間
  • 淨化後的 request / response 稽核資料
  • 錯誤碼、變更摘要與觀測性紀錄

3. 我們如何使用資料

  • 建立、維護與保護玩家帳號
  • 管理登入 session、偵測異常登入、防止濫用
  • 提供遊戲核心功能、同步進度、提供好友／聊天／郵件／兌換碼功能
  • 處理客服、爭議、刪帳號請求與法規遵循
  • 進行除錯、風險控管、資安、防弊與維運監控

4. 資料分享與第三方

除非有法律要求或提供服務所必要，我們不會出售您的個人資料。

我們可能在必要範圍內與主機、資料庫、維運、登入平台或付款平台分享資料，以提供遊戲、登入、部署、付款或法規流程。若委託第三方處理資料，我們會要求其僅在提供服務所必要的範圍內使用資料。

5. 保存、刪除與玩家權利

我們會在提供服務所需的期間內保存資料。當玩家提出刪帳號申請後，我們會撤銷登入 session、停止已刪除帳號再次登入，並啟動資料刪除、去識別化或限制存取流程。

部分資料可能因資安、防弊、爭議處理、備份、法規、稅務或會計需求而保留較長時間。若法律要求保留，我們會限制其用途。

玩家可透過 App 內入口或本網站的帳號刪除頁面進一步了解刪除流程。
